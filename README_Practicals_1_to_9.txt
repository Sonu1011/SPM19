SOFTWARE PROJECT MANAGEMENT — PROJECTLIBRE PRACTICALS 1–9

Included:
- SPM_General_Master_Template.xml: generalized plan with 20 main events and exactly 3 child events under each.
- SPM_Practical_1.xml through SPM_Practical_9.xml: individual practical files with the practical title and implementation notes.

Practical mapping:
1. Setup of Working Calendar
2. Project Task List and Schedule
3. Network (PERT) Diagram
4. Gantt Chart
5. Manage, Plan and Organize Project Activities
6. Hierarchical Task Structure Using Indent, Outdent and Split Task
7. Identify Project Tasks, Checkpoints and Milestones
8. Task Duration, Dependencies and Scheduling Constraints
9. Assign the Resources and Set the Notes for Resources

All files are Microsoft Project XML interchange files supported for import by ProjectLibre.
They are not native serialized .pod files. Open each XML in ProjectLibre, verify the relevant view/feature,
then use File > Save As and select ProjectLibre (*.pod) if a native .pod copy is required.

Practical-specific operations that require a user interaction in ProjectLibre:
- Practical 3: open Network Diagram / PERT view.
- Practical 4: open and capture Gantt Chart view.
- Practical 5: execute Split Task to create a real gap; test Indent and Outdent.
- Practical 6: change an upstream duration and observe downstream dates shift.
- Practical 8: apply a scenario-appropriate Start No Earlier Than constraint.
