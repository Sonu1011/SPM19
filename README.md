# Software Project Management – ProjectLibre Practicals (1–9)

**Tool:** ProjectLibre  
**Project duration:** 2 months (18 November 2026 – 18 January 2027)  
**Working calendar:** Monday–Friday, 8:00 AM–12:00 PM and 1:00 PM–5:00 PM

## Aim

To plan and manage a project using ProjectLibre by creating a working calendar, tasks, schedules, network and Gantt charts, task hierarchy, milestones, dependencies, constraints, and resource assignments.

## Practical 1: Setup of Working Calendar

**Aim:** Create a working calendar for the project.

**Steps:**
1. Open ProjectLibre and create a new project.
2. Enter the project name and start date.
3. Open **Project → Calendar**.
4. Set Monday to Friday as working days.
5. Set working hours to **8:00 AM–12:00 PM** and **1:00 PM–5:00 PM**.
6. Keep Saturday and Sunday as non-working days.
7. Save the project.

## Practical 2: Project Task List and Schedule

**Aim:** Create the project task list and schedule.

**Steps:**
1. Open the project and go to the **Gantt Chart** view.
2. Enter the project activities in the task name column.
3. Enter the duration of each task.
4. Arrange tasks in the required sequence.
5. Set task start dates or allow ProjectLibre to schedule them.
6. Check the project start and finish dates.
7. Save the project.

## Practical 3: Network (PERT) Diagram

**Aim:** Display the sequence and relationship between project activities.

**Steps:**
1. Open the project containing the task list.
2. Enter or verify the task dependencies.
3. Select the **Network Diagram** view.
4. Check the activity boxes and connecting arrows.
5. Verify that predecessor and successor relationships are correct.
6. Save the project.

## Practical 4: Gantt Chart

**Aim:** Create and view the project Gantt chart.

**Steps:**
1. Open the project in ProjectLibre.
2. Select the **Gantt Chart** view.
3. Enter task names and durations if not already entered.
4. Set task dependencies where required.
5. Review the task bars against the project timeline.
6. Adjust the timescale or column widths for clear presentation.
7. Save the project.

## Practical 5: Manage, Plan and Organize Project Activities

**Aim:** Organize project activities into a manageable plan.

**Steps:**
1. Create a new project and enter its activities.
2. Divide the work into major phases.
3. Add the activities required under each phase.
4. Arrange the activities in logical order.
5. Enter task durations and dependencies.
6. Review the overall schedule.
7. Save the project.

## Practical 6: Hierarchical Task Structure Using Indent, Outdent and Split Task

**Aim:** Create a task hierarchy and organize task execution.

**Steps:**
1. Enter the main project phases as summary tasks.
2. Add the related activities below each phase.
3. Select a child task and use **Indent** to place it under a parent task.
4. Use **Outdent** to move a task back to the higher level.
5. Select a task and use **Split Task** to show a break in its scheduled work.
6. Check the task hierarchy and schedule.
7. Save the project.

## Practical 7: Identify Project Tasks, Checkpoints and Milestones

**Aim:** Identify important tasks and project progress points.

**Steps:**
1. Enter all major project tasks.
2. Identify important review points as checkpoints.
3. Add milestone tasks for major achievements.
4. Set a milestone duration to **0 days**.
5. Place milestones at the appropriate points in the schedule.
6. Review the project timeline.
7. Save the project.

## Practical 8: Task Duration, Dependencies and Scheduling Constraints

**Aim:** Set task durations, relationships, and scheduling rules.

**Steps:**
1. Enter or review the duration of each task.
2. Open the task information or predecessor column.
3. Link dependent tasks using the appropriate predecessor.
4. Use parallel scheduling where activities can occur at the same time.
5. Open task information and review the **Advanced** settings.
6. Apply the required scheduling constraint to the selected task.
7. Check the updated schedule and save the project.

## Practical 9: Assign the Resources and Set the Notes for Resources

**Aim:** Add project resources and assign them to activities.

**Steps:**
1. Open the **Resource Sheet** view.
2. Enter the resource names and resource types.
3. Add the required resources, such as Project Manager, Business Analyst, Developer, Tester, and DevOps.
4. Open the Gantt Chart view.
5. Select a task and assign the appropriate resource.
6. Open resource information and add notes describing each resource's responsibilities.
7. Review the assignments and save the project.

## Final Result

A two-month project plan was prepared in ProjectLibre covering all nine practical topics. The plan contains **10 parent events**, with **3 child tasks under each parent event**, giving **30 child tasks** in total. The project also includes a working calendar, task schedule, dependencies, resource information, and notes.

## How to Open the Project

1. Open ProjectLibre.
2. Select **File → Open** and choose the project XML file.
3. Review the imported tasks, schedule, and resources.
4. Select **File → Save As** to save a native ProjectLibre `.pod` file.
